# Git Workflow

## Repository Initialization
Initialize the project using git init and use main as the primary branch.

## Daily Workflow
1. Check changes using git status.
2. Create or switch to a feature branch.
3. Stage changes using git add.
4. Commit using a descriptive commit message.
5. Push the branch to GitHub.
6. Open a Pull Request.
7. Review and merge approved changes.

## Useful Commands
- git status
- git branch -a
- git switch
- git add
- git commit
- git log --oneline --graph
- git push
- git pull
- git tag
